# ARCOS Point Settings

此檔案記錄透過 Point&Path 定義之點位座標。

> **格式定義與維護原則**：
> - **單點格式**：`$point=($x,$y,$z,$u,$v,$w)`
> - **多點陣列格式**：`$point[$index]=($x,$y,$z,$u,$v,$w)`
> - **更新原則**：同名點位或同索引若已存在則覆蓋座標；新點位則追加於下方。修改前必須先讀取現存點位，避免遺失機台既有點位資料。
